# ブランド別の引き継ぎメモ

会社全体の目標・理念・部署は `BUSINESS_PLAN.md`（本社）にあります。
ブランドごとの作業は、チャットを分けて、それぞれのメモから再開します。

| ブランド | メモ | 新しいチャットの最初に送る言葉 |
|---|---|---|
| 煦鈴（くりん）｜占い・恋愛動物診断 | `brands/kurin.md` | `brands/kurin.md と BUSINESS_PLAN.md の理念を読んで、続きからやって` |
| 50代からのキレイと暮らし｜美容・Pinterest・楽天 | `brands/kirei.md` | `brands/kirei.md と BUSINESS_PLAN.md の理念を読んで、続きからやって` |
| なお｜結婚30年の妻｜note | `brands/nao.md` | `brands/nao.md と BUSINESS_PLAN.md の理念を読んで、続きからやって` |
| 本社（全体の数字・週次チェック・新しい柱） | `BUSINESS_PLAN.md` | `BUSINESS_PLAN.md の進捗ログを読んで、続きからやって` |

## どのチャットでも守ること
- 会社の理念：誰かのために、誰かの幸せのために働く。人のために価値を提供する。法令を守る
- 説明はやさしい日本語で、手順はひとつずつ。リンクは毎回いちばん下に、コピーできる形で出す
- 測定IDや広告リンクなどの大事な文字は、スクリーンショットから読み取らず、コピーして送ってもらう
- 作業が終わったら、そのブランドのメモの「進捗」と「次にやること」を更新して、main に入れる（本社が毎朝8時にこのメモを読んで、その日の指示を出すため）
- ブランドどうしを混ぜない（アカウントも発信も別）
