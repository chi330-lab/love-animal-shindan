# やさしい出会いノート｜A8.net のリンクを貼るピン（2026-10-28）

リンクの貼り方：Pinterest のピンの「リンク先」に、下の URL を入れる。説明の**いちばん最初**に PR の1行を入れる。貼ったら、そのピンの URL を A8.net の「広告掲載URL管理」に登録する。

- リンク：`https://px.a8.net/svt/ejp?a8mat=4BED92+9Z0G3M+5SFC+BWVTE&a8sns=pinterest`
- PR の1行：`【PR】この投稿にはアフィリエイト広告が含まれます。`

## どのピンに貼るか（2026-10-28 更新：広げる）
- **貼る（8枚）**：第1弾の 1・2・4 と、第2弾の 6・7・8・9・10
- **貼らない（2枚）**：3「お金の話が出たら」（だましへの注意に登録ボタンを合わせるのは、読む人のためにならない）、5「疲れたら休んでいい」（休んでいい、と言うピンにアプリへのリンクは合わない）
- 貼るピンも、説明は「登録をすすめる」書き方にしない。最後に「使うかどうかは、自分のペースで決めて大丈夫です」と添える（A8.net の PR 文は使わない）
- 目標は「1日10万円」。成果報酬は新規無料登録 3,000円／件 なので、ピン1枚ずつではなく、**リンクつきピンを毎週増やし続ける**。数字（クリック・登録）が出たテーマを、似たテーマで増やす
