【ブランド】
- 読む人：50代の女性。キレイに憧れるけれど、今の暮らしは理想から遠いと感じている人
- 考え方：年齢にあらがうのではなく、「今の自分を機嫌よく扱う、お守りのようなひと手間」を届ける
- 言葉づかい：やさしく、共感から始める。読む本人に向けて書く

【よく見られているピンの形】
- 画像：50代の日本人女性の、写真のような画像。明るい自然光、白・ベージュ・木の色。**画像に文字は入れない**
- タイトル：具体的な悩みを、本人の本音に近い言葉で（例：「出かける前のアホ毛」「染めても2週間で、根元がキラッ…」）。そのあとに「｜」で、やさしいひと手間を書く

【50代の髪のリアルな悩み（タイトルの材料）】
- 白髪：染めても1〜2週間で根元が気になる／美容院代がかさむ、セルフ染めはゴワゴワ／分け目の白髪で老けて見える
- うねり・広がり：夜まっすぐ乾かしたのに朝うねる／湿気の日に広がる／アホ毛・チリ毛でだらしなく見えないか心配
- ボリューム・分け目：お昼の鏡で分け目がぱっくり／トップがぺたんとして服がキマらない
- ほかに：パサつき、ツヤ、乾かす時間、手元の乾燥、自分の時間がない

【必ず守るルール（法律）】
1. 説明文のはじめに【PR】、ハッシュタグに #PR を必ず入れる（ステマ規制）
2. 効き目をうたわない（薬機法）。使わない言葉の例：シワが消える、若返る、白髪が治る・減る・予防、育毛、抜け毛が減る、頭皮の血行促進、うねりが治る、湿気をブロック、ダメージ補修、髪質改善、高浸透、くせ毛が直る
   → 書いてよいのは、使い方・場面・香り・手ざわり・気分（例：「パフでポンポンとのせるだけ」「シャンプーしながら少しずつ色づく」「手のひらで温めて毛先からなじませる」）
3. 言い過ぎない（景品表示法）：No.1、楽天1位、絶対、必ず、〇倍、期間限定のクーポンやポイントは書かない
4. 説明文の最後に「※画像はイメージです。商品とは形が異なる場合があります」を入れる
5. 不安をあおらない。悩みは共感として書き、すぐあとにやさしいひと手間を置く

【画像の言葉のルール】
- 人物は「50代の日本人女性」。服を着た場面にする（お風呂・肌が見える場面は使わない）
- 別のメーカーの商品にそっくりな形を写さない。商品は脇役でよい
- 最後に「文字は入れない。」を入れる

【同じピンばかりにしないために】
- 1日にたくさん出すときは、同じ商品・同じリンクが続かないように混ぜる
- 同じ商品でも、場面（朝の鏡・玄関・寝室・洗面所など）とタイトルを毎回変える

【出す形】ピン1枚ごとに、この順で書く
1. 画像の言葉（AI に伝える日本語）
2. タイトル（100文字以内）
3. 説明（500文字以内。【PR】で始め、※画像はイメージです…と #PR を入れる）
4. リンク（上の表からそのまま）
5. ボード名
6. 代替テキスト（画像の内容を1〜2文で）

【今日の依頼】
（例）髪の悩みのピンを5枚。白髪2枚・うねり1枚・アホ毛1枚・ボリューム1枚。商品が続かないように。

## Claude への報告のしかた
投稿や予約がすんだら、このチャットに次のように送る。Claude がメモと `pins/pin-texts.md` に記録する。
```
投稿した（または予約した）：
・10/20 タイトル「〇〇」 商品：〇〇 ボード：〇〇
・10/21 タイトル「〇〇」 商品：〇〇 ボード：〇〇
```
新しい商品を使いたいときは、楽天のリンク（a.r10.to）と商品名を Claude に送る → Claude が表とサイトに足す。
