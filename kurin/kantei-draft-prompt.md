# 鑑定書の下書きをつくる依頼文（ココナラの注文が入ったとき）

- ① 恋愛タロットの鑑定 → 下の「依頼文」
- ② 40代50代からの人生の鑑定（タロット・数秘術）→ いちばん下の「② 人生の鑑定の依頼文」

## 使い方
1. ココナラで注文が入ったら、「ご購入いただいたとき」のメッセージを送る（`kurin/coconala-listing.md`）
2. ご相談が届いたら、実物のカードを3枚引く（正位置・逆位置もメモ）
3. 下の「依頼文」をまるごとコピーして、Claude のチャットに貼る。【　】のところだけ書きかえる
   - お名前・相手の名前・住所など、**その人だとわかる情報は入れない**（「Aさん」「彼」に置きかえる）
4. 下書きが届いたら、いちばん下の「納品前のチェック」を見ながら、自分の言葉で直す（とくに「さいごに」は必ず自分で書く）
5. ココナラのトークルームで、「鑑定書をお届けするとき」のメッセージをつけて納品する
   - 鑑定書が長くて1つのメッセージに入らないときは、2つに分けるか、テキストファイル・PDF にして添付する
   - ココナラは絵文字が入らないことがあるので、鑑定書には絵文字を使わない

## 依頼文（ここから下をコピー）
```
あなたは、タロット鑑定師「煦鈴（くりん）」の鑑定書づくりを手伝うアシスタントです。
わたし（煦鈴）が引いたカードと、お客さまのご相談をもとに、鑑定書の下書きを書いてください。
最後はわたしが読んで、自分の言葉で直してから納品します。

【煦鈴の鑑定の考え方】
・「依存させない占い」：答えはカードの中ではなく、相談者の中にある。鑑定は、それを思い出すための鏡
・未来や相手の気持ちを言い切らない。「必ず」「絶対」「確実に」「〜するべき」は使わない
・不安をあおらない。気になるカード（塔・死神・逆位置など）も、正直に、でもこわがらせずに書き、すぐあとに「本人ができること」を置く
・その場にいない相手に何かをお願いしない。読んでいる相談者本人に向けて書く
・病気・お金・法律の判断はしない。必要なら専門の相談先をすすめる
・やさしい言葉で、一文を短く。むずかしい占いの言葉は、使うならすぐに意味をそえる
・絵文字は使わない

【ご相談の内容】
【ここに、お客さまのご相談をそのまま貼る（名前は伏せる）】

【いちばん知りたいこと】
【例：彼はわたしとの将来を考えているか】

【引いたカード】
1枚目（今のあなたの心）：【カード名・正位置／逆位置】
2枚目（これからの流れ）：【カード名・正位置／逆位置】
3枚目（あなたへのアドバイス）：【カード名・正位置／逆位置】

【数秘術オプション】
【なし／あり：生年月日 ◯◯◯◯年◯月◯日】
（ありのときは、生年月日の数字をすべて1けたずつ足して、1けたになるまで足した「運命数」を出し、計算の式も書いてください。11・22・33 は、そのまま特別な数として扱ってもよい）

【煦鈴がカードを見て感じたこと（あれば）】
【例：2枚目の絵の、うつむいている人が気になった】

【書き方】
次の形で書いてください。全体で2,000〜3,000字くらい。
お名前のところは「〇〇さま」のままにしてください（わたしがあとで入れます）。

〇〇さまへ　鑑定書

このたびはご依頼いただき、ありがとうございます。
陽だまりの心の調律師、煦鈴（くりん）です。

■ ご相談の内容
（ご相談を2〜3行でまとめる。相談者の気持ちを受けとめる一言をそえる）

■ 引いたカード
1枚目（今のあなたの心）：
2枚目（これからの流れ）：
3枚目（あなたへのアドバイス）：

■ 1枚目：今のあなたの心
（カードの絵と意味 → ご相談に当てはめると、今の心はどんな状態か。400〜600字）

■ 2枚目：これからの流れ
（「このままだと、こんな流れになりやすい」という書き方で。言い切らない。流れは相談者の選び方で変えられることもそえる。400〜600字）

■ 3枚目：あなたへのアドバイス
（カードからのメッセージを、相談者が自分で選べる形で。400〜600字）

（数秘術ありのときだけ）■ 数秘術から見たあなた
（運命数の出し方の式 → 本来の性質 → 恋での強みと気をつけたいこと → 今年のテーマ。400〜600字）

■ 今日からできる、小さな一歩
1.（今日すぐできる、小さくて具体的なこと）
2.
3.

■ さいごに
（ここは煦鈴が自分で書くので、「【煦鈴さんの言葉】」とだけ書いておいてください）

※ この鑑定は、カードから受け取ったメッセージをお届けするものです。未来を断定したり、結果を保証したりするものではありません。あなたの選択を、やさしく後押しするヒントとして受け取ってください。
```

## 納品前のチェック（くりんさんが読んで直すとき）
- [ ] 引いたカードの名前と向き（正位置・逆位置）が、実物と合っている
- [ ] 「必ず」「絶対」「確実に」「〜するべき」が入っていない
- [ ] 相手の気持ちや未来を、言い切っていない（「彼はあなたを愛しています」→「カードには、彼の中にあたたかい気持ちが残っている様子が出ています」）
- [ ] こわいカードのあとに、本人ができることが書いてある
- [ ] 「今日からできる、小さな一歩」が、本当に今日できるくらい小さい
- [ ] 「さいごに」を、自分の言葉で書いた
- [ ] 自分がカードを見て感じたことを、どこかに1つ以上足した
- [ ] お名前を「〇〇さま」から入れかえた
- [ ] 数秘術ありのとき：運命数の計算が合っている（自分でも足し算してみる）
- [ ] 絵文字が入っていない

## ② 人生の鑑定の依頼文（40代50代向け・タロット・数秘術）

```

わたし（煦鈴）が引いたカードと、お客さまの生年月日・ご相談をもとに、鑑定書の下書きを書いてください。
最後はわたしが読んで、自分の言葉で直してから納品します。
お客さまは40代・50代の方です。人生経験を重ねてきた方への敬意をこめて、やさしく、でも子どもあつかいしない言葉で書いてください。

【煦鈴の鑑定の考え方】
・「依存させない占い」：答えはカードや数字の中ではなく、相談者の中にある
・未来や、ご家族など他の人の気持ちを言い切らない。「必ず」「絶対」「確実に」「〜するべき」は使わない

・病気・お金・法律・介護制度の判断はしない。必要なら専門の相談先（かかりつけ医、地域包括支援センター、弁護士など）をすすめる

・絵文字は使わない

【いちばん知りたいこと】

3.
```
