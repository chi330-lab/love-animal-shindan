## 1日目　妻の本音
```
妻として30年暮らして思うこと。

女性が結婚前に見ているのは、年収よりも
「意見が違ったとき、話を聞いてくれるか」
だったりします。

完璧な答えより、
「じゃあ、どうしようか」と言える人。
それだけで、ずいぶん安心できるんです。
```

## 2日目　問いかけ
```
「この人でいいのかな」と迷うとき。

その不安は、
・結婚そのものが怖い
・彼女との間に確かめたいことがある
のどちらに近いですか？

ここを分けるだけで、
考えることがぐっと減ります。
```

## 3日目　30年の気づき
```
結婚生活の大部分は、特別な日ではなく
「普通の日」です。

プロポーズや結婚式は一瞬。
その後に続くのは、何千日もの、
ごはんと家事と、ちょっとした会話。

「この人と普通の日を過ごせるか」
考えてみてください。
```

## 4日目　具体的なヒント
```
大事な話をするとき、
いきなり「話があるんだけど」は要注意。

彼女は「別れ話かも」と身構えます。

「結婚を真剣に考えてるから、
今のうちに話しておきたいことがあって」

最初に目的を伝えるだけで、
話し合いはずっと穏やかになります。
```

## 5日目　妻の体験談
```
新婚のころ、夕食のたびに
「私はあなたの家政婦じゃない」
と思っていました。

一度、正直にそう伝えたら、
夫はその日から食器を洗うようになりました。

言わなきゃ伝わらないこと、
言えば変わることもあるんです。
```

## 6日目　問いかけ
```
結婚前に、彼女とこの話、できていますか？

・毎月いくら貯金したいか
・家事をどう分けるか
・子どものこと
・お互いの親との距離

全部じゃなくて大丈夫。
まずは1つだけ、話してみませんか。
```
