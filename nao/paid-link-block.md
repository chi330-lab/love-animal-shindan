# 無料記事の最後に入れる「有料記事への案内」

## 使い方
1. note で無料記事（まずは「価値観が違う＝相性が悪い」）の編集画面を開く
2. いちばん最後に、下の文章を貼る
3. URL の行は、貼ったあと Enter を押すと、記事のカード（画像つき）になる
4. 「100%安心できるまで待たなくて…」にも同じように貼る（2つ目の文章を使う）

> 売り込みに見えないように、**記事の内容の続きとして** 案内します。「今すぐ」「必ず」などの言葉は使いません（理念2）。

---

## 「価値観が違う＝相性が悪い」の最後に入れる文章
```
ここまで読んでくださって、ありがとうございます。

「価値観の違いは、話し合えばいい」
そう分かっていても、
何から、どう話せばいいのかで止まってしまう方も多いと思います。

そんな方のために、
不安を書き出して、分けて、彼女と話して、自分で決めるまでの手順を、
1冊のガイドにまとめました。

無料で読める部分だけでも、整理を始められるように書いています。
よかったら、のぞいてみてください。

https://note.com/novel_sable3927/n/n1d60ed51b931
```
